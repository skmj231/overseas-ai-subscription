웹에서 결제한 경우

  1. 갱신부터 중단
    ChatGPT → 계정 메뉴 → 설정 → 결제(Billing) → 플랜 취소. 다음 결제 최소 24시간 전에 처리하세요.
  2. 환불은 도움말 채팅에서 요청
    결제된 계정으로 help.openai.com에 로그인한 뒤 우측 아래 채팅 → 환불 요청을 선택합니다.
  3. 접수 증거 보관
    결제일·금액·인보이스, 요청 시각과 접수 화면을 캡처합니다.

App Store 결제

해지: iPhone 설정 → 이름 → 구독 → ChatGPT → 구독 취소

환불: reportaproblem.apple.com에서 Apple에 직접 요청합니다. 환불 요청만으로 구독이 해지되지는 않으므로 두 절차를 모두 처리하세요.

Google Play 결제

해지: Play 스토어 → 구독 → ChatGPT → 구독 취소

환불: ChatGPT 결제 계정으로 OpenAI 도움말에 로그인해 채팅으로 요청합니다. 승인 시 공식 안내상 처리까지 최대 10영업일이 걸릴 수 있습니다.
