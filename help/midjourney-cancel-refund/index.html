결론

Midjourney 웹 계정의 구독 관리 화면에서 자동 갱신을 취소하세요. 환불 버튼이나 안내가 표시되면 화면의 자격 조건을 확인해 즉시 요청하고, 표시되지 않으면 결제 영수증과 사용량을 첨부해 공식 지원으로 문의하세요.

실행 순서

  1. midjourney.com/account에 결제한 계정으로 로그인
  2. 구독 관리에서 현재 플랜이 월간인지 연간인지, 다음 갱신일이 언제인지 캡처
  3. 플랜 취소를 선택하고 ‘기간 종료 시 취소’ 상태가 표시되는지 확인
  4. 이미 갱신됐다면 같은 화면의 환불 가능 안내를 확인하고 즉시 요청
  5. 환불 선택지가 없다면 결제일·인보이스·사용량과 함께 지원 문의
