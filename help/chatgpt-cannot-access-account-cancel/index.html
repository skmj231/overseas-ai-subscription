실제로 끝내는 순서

  1. 영수증 판매자부터 확정메일과 카드 명세서에서 서비스·Apple·Google 중 누가 결제했는지 확인합니다.
  2. 계정 복구를 한 번 시도로그인 방식을 바꾸지 말고 가입할 때 사용한 이메일·Google·Apple·Microsoft 버튼으로 다시 시도합니다. 회사 이메일을 잃었다면 복구보다 지원 취소가 빠를 수 있습니다.
  3. 기다리지 말고 결제 중단도 접수help.openai.com 오른쪽 아래 채팅 → Billing → Cancel subscription → 계정 접근 불가 설명
  4. 종료일을 문장으로 받기“Recurring billing is canceled”와 적용일이 적힌 답변·화면을 저장합니다.

자주 실패하는 경우

다른 로그인 방식: 같은 이메일처럼 보여도 이메일 로그인과 Apple·Google·Discord 로그인은 다른 계정일 수 있습니다.

앱을 이미 삭제함: 앱 삭제는 정기 결제를 끝내지 않습니다. Apple 또는 Google 구독 목록에서 처리합니다.

지원팀이 계정을 못 찾음: 전체 카드번호 대신 결제일·금액·통화·끝 4자리·인보이스 번호를 한 번에 제출합니다.

확인 1: Apple의 이메일 가리기 주소를 썼다면 Apple ID의 로그인 및 보안에서 전달 주소를 확인합니다.

확인 2: ChatGPT 구독과 OpenAI API 사용료는 별개입니다. API 결제는 platform.openai.com의 조직·프로젝트를 따로 확인합니다.

확인 3: 계정 삭제는 광고 계정 등 다른 서비스 접근에도 영향을 줄 수 있으므로 구독 중단만 필요할 때 먼저 삭제하지 않습니다.
