앱스토어 결제라면 서비스 로그인 없이 직접 취소할 수 있습니다. 웹 결제일 때만 계정 복구와 결제 중단 요청을 병행합니다.

Gemini 계정에 로그인할 수 없어도 구독 자체가 자동으로 멈추지는 않습니다. 비밀번호 재설정이나 소셜 로그인 복구에 시간이 걸리는 동안 다음 결제일이 지나갈 수 있으므로, 계정 복구와 결제 중단을 같은 날 병행하는 것이 안전합니다.

먼저 영수증을 찾아 웹·Apple·Google 중 실제 결제처를 확인하세요. 앱스토어 결제는 Gemini 로그인 없이도 스토어 계정에서 직접 취소할 수 있습니다. 웹 직접 결제이고 계정에 접근할 수 없을 때만 최소한의 거래 정보로 공식 지원에 계정 식별과 갱신 중단을 요청합니다.

1. 왜 이런 문제가 생기나요?

Gemini 로그인 메일을 받지 못하거나 소셜 로그인 계정을 잃어버려도 결제는 별도로 자동 갱신될 수 있습니다. 계정 복구와 결제 중단은 담당 경로와 걸리는 시간이 다르므로 같은 날 병행해야 다음 청구를 놓치지 않습니다.

Gemini 화면이 아니라 Google One 또는 Google Play에 상품명이 표시될 수 있습니다. 저장공간 한도와 가족 공유에 미치는 영향도 취소 전에 확인하세요.

2. 실제 결제한 곳을 찾는 방법

카드 앱의 가맹점명만 보지 말고 이메일 영수증의 발신자와 주문번호를 확인하세요. 판매자가 누구인지에 따라 취소 화면과 환불 창구가 달라집니다. 아래 표에서 영수증이 실제로 존재하는 행만 따라가면 됩니다.

영수증 수신 주소와 가입 주소가 다를 수 있습니다. Apple 로그인 시 이메일 가리기를 사용했거나, 회사·학교 계정으로 가입했거나, Google 로그인을 선택했는지 차례로 확인하세요.

3. 계정 복구와 결제 중단을 병행하는 이유

영수증 이메일과 로그인 방식을 확인해 계정 복구를 진행하세요. 동시에 Apple·Google·Galaxy Store 영수증이라면 서비스 로그인 없이 스토어 구독 화면에서 직접 다음 결제를 끌 수 있습니다.

웹 직접 결제이고 계정 접근이 불가능할 때만 결제일·금액·카드 끝 4자리로 계정 식별을 요청합니다. 전체 카드번호, CVC, 비밀번호는 보내지 않습니다.

4. Gemini에서 처리하는 순서

계정 복구만 계속 시도하다가 결제일을 놓치지 않도록, 복구 시도와 구독 중단 시도를 각각 기록하세요. 스토어 결제를 찾았다면 복구 결과를 기다리지 말고 먼저 다음 갱신을 끌 수 있습니다.

  1. 영수증의 판매자 확인메일 발신처와 주문번호를 보고 Gemini 웹, Apple, Google 중 실제 결제처를 정합니다.
  2. 원래 로그인 방식 복구이메일, Google, Apple, Discord 등 가입 당시 방식을 순서대로 확인합니다.
  3. 스토어 결제는 직접 중단Apple·Google 영수증이면 해당 스토어 구독에서 바로 취소합니다.
  4. 웹 결제만 식별 요청로그인 복구가 안 되고 다음 결제가 임박했을 때 공식 결제 지원에 최소 정보만 보냅니다.

5. 흔히 막히는 상황과 해결 방법

로그인 메일이 오지 않는다면 스팸함과 차단 목록뿐 아니라 가입 당시 사용한 소셜 로그인 버튼도 확인하세요. 같은 이메일 주소처럼 보여도 이메일 로그인과 Google·Apple 로그인은 서로 다른 계정으로 만들어질 수 있습니다.

다음 결제가 임박했다면 완벽한 계정 복구를 기다릴 필요가 없습니다. 앱스토어 구독은 직접 취소하고, 웹 결제는 공식 결제 지원에 갱신 중단을 함께 요청하세요.

로그인 메일이 안 옴스팸함, 차단 목록, 이메일 철자와 가입 당시 소셜 로그인을 확인합니다.

어느 계정인지 모름메일함의 영수증, 주문번호, 결제일을 기준으로 계정을 역추적합니다.

다음 결제가 임박앱스토어 결제는 먼저 직접 취소합니다. 웹 결제만 공식 결제 지원에 긴급 중단을 요청합니다.

6. 직접 해결되지 않을 때만 문의하세요

지원팀 문의가 필요한 경우

앱스토어에서 직접 취소할 수 없고 웹 결제 계정에도 접근할 수 없을 때만 문의합니다.

지원팀은 앱스토어 취소를 대신하는 곳이 아닙니다. 실제 결제가 웹에서 이루어졌고 로그인 복구도 되지 않아 사용자가 직접 구독 화면에 들어갈 수 없을 때만 계정 식별과 갱신 중단을 요청하세요.
