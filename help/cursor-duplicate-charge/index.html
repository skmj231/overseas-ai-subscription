1. 왜 이런 문제가 생기나요?

Cursor 결제가 두 번 보이는 가장 흔한 이유는 승인 대기와 매입 완료가 함께 표시되거나, 웹과 앱스토어·서로 다른 계정에 구독이 각각 생긴 경우입니다. 거래번호와 상태를 보지 않고 하나를 환불 요청하면 유지하려던 구독까지 중단될 수 있습니다.

구독료와 사용량 기반 온디맨드 비용은 별개입니다. 이미 소비한 온디맨드 사용량은 구독 환불 판단과 분리해 확인합니다.

2. 실제 결제한 곳을 찾는 방법

카드 앱의 가맹점명만 보지 말고 이메일 영수증의 발신자와 주문번호를 확인하세요. 판매자가 누구인지에 따라 취소 화면과 환불 창구가 달라집니다. 아래 표에서 영수증이 실제로 존재하는 행만 따라가면 됩니다.

3. 실제 중복인지 직접 판별하는 방법

  1. 두 거래번호 비교거래번호가 같고 하나가 승인 대기라면 중복 청구가 아닐 수 있습니다.
  2. 매입 완료 확인서로 다른 두 건이 모두 매입 완료됐는지 카드사 앱이나 상담으로 확인합니다.
  3. 활성 구독 개수 확인웹, 앱스토어, 다른 이메일, 팀 계정에 각각 활성 플랜이 있는지 대조합니다.
  4. 필요 없는 구독만 취소유지할 계정을 먼저 정하고 나머지 구독의 다음 갱신을 중단합니다.
한 건이 승인 대기라면매입 여부를 기다려 확인합니다. 즉시 환불 문의를 보낼 필요는 없습니다.

4. Cursor에서 처리하는 순서

  1. 영수증의 판매자 확인메일 발신처와 주문번호를 보고 Cursor 웹, Apple, Google 중 실제 결제처를 정합니다.
  2. 두 건의 매입 상태 확인승인 대기와 매입 완료를 구분합니다.
  3. 구독 경로 대조웹·앱스토어·다른 이메일의 활성 구독을 비교합니다.
  4. 중복 구독만 취소유지할 구독은 건드리지 않고 중복된 경로만 다음 갱신을 끕니다.
Cursor에서 특히 확인할 점구독료와 사용량 기반 온디맨드 비용은 별개입니다. 이미 소비한 온디맨드 사용량은 구독 환불 판단과 분리해 확인합니다.

5. 흔히 막히는 상황과 해결 방법

두 줄 중 하나가 사라짐임시 승인이 해제된 것입니다. 실제 중복 결제가 아니므로 환불 요청이 필요 없습니다.

두 건 모두 매입 완료각 거래번호와 겹친 이용기간을 모아 결제한 판매자에게 중복분만 환불 요청합니다.

웹과 앱 구독이 모두 활성유지할 경로를 정한 뒤 다른 구독을 직접 취소합니다. 양쪽을 모두 취소하지 않도록 주의하세요.
