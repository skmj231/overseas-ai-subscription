가장 최근 결제가 14일 안이고 새 결제 주기에 사용하지 않았다면 Cursor 지원팀에 즉시 검토를 요청하세요. 다음 갱신도 막으려면 Dashboard의 Billing에서 별도로 취소해야 합니다. 약관상 갱신 최소 24시간 전 취소가 안전합니다.

1. 왜 이런 문제가 생기나요?

Cursor에서 구독을 취소하는 일은 다음 자동결제를 막는 절차이고, 이미 빠져나간 돈을 돌려받는 환불은 별도의 심사입니다. 두 절차를 하나로 생각하면 해지만 하고 환불을 기다리거나, 환불 문의만 보낸 채 다음 갱신을 놓치기 쉽습니다.

이 글에서는 먼저 영수증을 발행한 곳을 찾고, 그다음 Cursor 계정과 결제 상태를 함께 확인한 뒤, 실제로 문제가 끝났는지 확인하는 순서로 설명합니다.

3. 계정 복구와 결제 중단을 병행하는 이유

계정 확인은 영수증·플랜·사용 기록을 찾기 위해 필요하고, 결제 중단은 다음 갱신을 막기 위해 필요합니다. 한쪽 결과만 기다리면 취소 시점이나 증빙을 놓칠 수 있으므로 두 작업을 같은 날 병행하는 편이 안전합니다.

4. Cursor에서 구체적으로 처리하는 방법

  1. 사용을 멈추고 증빙 저장환불을 검토받을 결제 주기에 사용량이 없어야 하므로 새 요청·에이전트·온디맨드 사용을 중단하고 Usage 화면을 캡처합니다.
  2. 다음 갱신 먼저 중단Dashboard → Billing → Manage Subscription에서 취소하고 종료일 화면을 저장합니다.
  3. 지원팀에 가장 최근 결제만 특정계정 이메일, 결제일, 금액, 인보이스 ID, 사용하지 않았다는 사실을 한 번에 보냅니다.
  4. 5~10영업일 후 명세서 확인승인되면 원 결제수단으로 돌아온다는 안내가 있으므로 승인 메일과 실제 입금을 따로 확인합니다.

5. 흔히 막히는 상황과 해결 방법

취소 버튼이 없음: 이미 Hobby 플랜이거나 미납 인보이스가 있거나 Teams 멤버일 수 있습니다. Billing의 현재 플랜·미납·관리자 권한을 차례로 확인합니다.

14일 안이지만 사용함: 공개 정책상 일반적으로 환불되지 않습니다. 오결제·중복결제·법정 권리 등 구체적 예외가 있다면 사실만 적어 수동 검토를 요청합니다.

온디맨드·빠른 요청 비용: 이미 사용한 사용량 기반 비용은 구독 환불과 별개이며 환불되지 않는다고 안내됩니다.

차지백 진행 중: 지원팀 처리와 카드사 분쟁을 동시에 진행하면 지연되거나 계정 상태에 영향을 줄 수 있습니다. 먼저 Cursor에 문의하고, 해결되지 않을 때 카드사 절차를 검토합니다.
