1. 거래의 정체를 10분 안에 확인하세요

  1. 카드 내역 저장
    가맹점명, 결제일, 금액, 통화, 승인 상태, 승인번호를 기록합니다.
  2. 이메일 영수증 검색
    OpenAI, ChatGPT, Apple, Google과 같은 키워드로 결제일 전후 메일을 찾습니다.
  3. 모든 계정 대조
    개인·회사·예전 이메일의 ChatGPT 구독과 OpenAI Platform 결제 내역을 확인합니다.
  4. 가족·팀 사용 확인
    같은 카드를 쓴 사람이 있는지 묻되 카드 전체 번호를 공유하지 않습니다.

2. 어떤 결제인지 구분하세요

OpenAI에 신고: 도움말 채팅의 Payments and Billing에서 Fraud or unrecognized charges 경로를 이용합니다. 날짜·금액·카드 끝 4자리와 계정 이메일을 제출하되 전체 카드번호와 CVC는 보내지 않습니다.
