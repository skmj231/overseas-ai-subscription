다만 기억나지 않는 결제를 오래 방치하면 다음 정기결제가 이어질 수 있습니다. 먼저 영수증과 계정을 짧게 대조하고, 본인 결제가 아니라는 정황이 강하거나 추가 승인 시도가 보이면 서비스 답변을 기다리지 말고 카드를 잠그는 순서로 진행하세요.

1. 왜 이런 문제가 생기나요?

Grammarly의 카드 명세서 표기는 제품명, 법인명 또는 결제대행사명으로 나타날 수 있습니다. 예전에 만든 계정, 다른 이메일, 가족·팀 계정에서 정상 결제된 경우도 있으므로 곧바로 도용으로 단정하지 말고 확인하되, 추가 승인이 이어진다면 카드 잠금이 우선입니다.

개인 Premium/Pro, Business 좌석, Apple·Google 모바일 구독은 결제 주체가 다릅니다. 계정 삭제와 구독 취소도 같은 작업이 아닙니다.

2. 실제 결제한 곳을 찾는 방법

카드 앱의 가맹점명만 보지 말고 이메일 영수증의 발신자와 주문번호를 확인하세요. 판매자가 누구인지에 따라 취소 화면과 환불 창구가 달라집니다. 아래 표에서 영수증이 실제로 존재하는 행만 따라가면 됩니다.

3. 판매자 문의 전에 직접 확인할 것

각 확인 결과는 “찾음/없음”으로 간단히 적어 두세요. 어디까지 확인했는지 기록이 있어야 같은 계정을 반복해서 뒤지지 않고, 나중에 카드사나 판매자에게도 확인 범위를 명확하게 설명할 수 있습니다.

  1. 카드 거래 상태 확인승인 대기인지 매입 완료인지, 해외 원화결제인지 원통화 결제인지 봅니다.
  2. 메일함 전체 검색Grammarly, receipt, invoice, subscription, payment와 결제 금액을 검색합니다.
  3. 다른 계정 대조예전 이메일, Apple ID, Google 계정, 팀 관리자 메일의 구독 화면을 확인합니다.
  4. 도용 가능성 판단본인·가족·회사 결제가 아니거나 추가 승인 시도가 보이면 즉시 카드를 잠그고 카드사에 신고합니다.
정상 구독을 찾았다면유지하거나 직접 해지하면 됩니다. 판매자에게 문의할 필요가 없습니다.

4. Grammarly에서 처리하는 순서

정상 구독을 찾았다면 그 자리에서 유지할지 다음 갱신을 끌지 결정하면 됩니다. 본인 결제가 아니라면 계정 찾기에 시간을 더 쓰기보다 카드 보호와 거래 이의 제기를 먼저 진행하세요.

  1. 영수증의 판매자 확인메일 발신처와 주문번호를 보고 Grammarly 웹, Apple, Google 중 실제 결제처를 정합니다.
  2. 계정과 금액 대조모든 이메일과 팀 계정에서 같은 금액의 인보이스를 찾습니다.
  3. 정상 결제면 직접 정리계정이 확인되면 유지 또는 취소를 선택합니다.

5. 흔히 막히는 상황과 해결 방법

영수증이 없다는 이유만으로 바로 도용으로 단정할 필요는 없습니다. 스팸함, 삭제된 메일, Apple의 비공개 이메일 주소, 예전 Google 계정처럼 영수증이 다른 곳에 있을 가능성을 먼저 짧게 확인하세요.

반대로 본인·가족·회사 누구도 사용하지 않았고 비슷한 승인 시도가 반복된다면 판매자 문의보다 카드 잠금이 우선입니다. 판매자가 구독을 취소해도 노출된 카드정보 자체가 안전해지는 것은 아니기 때문입니다.

영수증을 못 찾음스팸함, 삭제된 메일, 다른 이메일, 가족·회사 계정을 확인하고 카드 명세서 원문을 보존합니다.

서비스가 계정을 못 찾음결제일·금액·통화·카드 끝 4자리·명세서 표기만 제공합니다. 전체 카드번호나 CVC는 보내지 않습니다.

본인 결제가 확실히 아님판매자 답변을 기다리지 말고 카드 잠금과 카드사 신고를 먼저 진행합니다.

모든 계정과 영수증을 확인해도 판매자를 식별할 수 없을 때 문의합니다. 본인 결제가 확실히 아니면 지원팀 답변보다 카드 잠금·카드사 신고가 먼저입니다.

지원팀은 계정과 거래를 연결할 단서가 있지만 사용자가 직접 찾지 못했을 때 도움을 받을 수 있는 마지막 경로입니다. 결제가 명백히 미승인 거래라면 지원팀 답변을 기다리지 말고 카드사 조치를 병행하세요.
