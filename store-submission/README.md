## 대시보드에서 할 일

1. 개발자 대시보드 → Donna 항목 → **패키지**에서 새 ZIP 업로드.
2. **스토어 등록정보**
   - 이름: `Donna 도나: 해외 AI·SaaS 구독 결제 전 알림`
   - 요약(132자 이내): `해외 AI·SaaS 구독의 다음 결제를 원화 예상액과 함께 며칠 전에 알려드립니다. 구독 3개까지 무료.`
   - 상세 설명: `listing-description-ko.txt` 전체
   - 카테고리: 생산성 / 언어: 한국어
   - 홈페이지 `https://donna.co.kr/` · 지원 `https://donna.co.kr/guide.html`
   - 아이콘·홍보 이미지·스크린샷 교체
3. **개인정보 보호 관행** — 아래 표대로 답한다.
4. **결제 및 배포**: "이 항목에 앱 내 결제가 있습니다"는 **아니오**(결제는 웹사이트에서만). 설명에 가격이 명시돼 있다.
5. 변경사항 설명에 `release-notes-1.5.0-ko.txt` 붙여넣기.
6. 경고가 없으면 **검토를 위해 제출**.

## 단일 목적 설명 (Single purpose)

> 사용자가 직접 등록한 해외 AI·SaaS 구독의 다음 결제일을 결제 전에 알려주고, 원화 예상 청구액과 해지 화면 링크를 함께 보여주는 것.

## 권한 사유 (Permission justification)

| 권한 | 사유 (그대로 붙여넣기) |
|---|---|
| `sidePanel` | 툴바 아이콘을 눌렀을 때 팝업 대신 브라우저 오른쪽 패널에 구독 목록과 등록 화면을 표시합니다. 탭을 바꿔도 유지되어 결제 화면을 보면서 등록할 수 있습니다. |
| `storage` | 사용자가 등록한 구독 목록, 알림 설정, 사업자등록번호, 결제 기록을 사용자의 브라우저(chrome.storage.local)에만 저장합니다. 서버를 운영하지 않습니다. |
| `alarms` | 하루 두 번 깨어나 등록된 결제일·무료 체험 종료일이 알림 시점에 들어왔는지 확인합니다. |
| `notifications` | 결제 며칠 전과 무료 체험 종료 전에 Chrome 알림을 표시합니다. 설정에서 끄거나 시점을 바꿀 수 있습니다. |
| `activeTab` | 사용자가 툴바 아이콘을 누르고 '이 결제창에서 켜기'를 선택한 그 순간 그 탭에서만 화면 텍스트를 읽어 서비스명·금액·주기를 채웁니다. |
| `scripting` | 위 activeTab 동작과, 사용자가 직접 허용한 사이트에 결제창 안내를 표시하기 위한 콘텐츠 스크립트 등록에 사용합니다. |
| 호스트 권한(결제 도메인) | Stripe·Paddle·PayPal 등 결제 페이지에서만 화면의 금액·주기·서비스명을 읽어 등록을 제안합니다. 카드번호 입력칸의 값은 읽지 않습니다. 전체 목록은 개인정보처리방침 5항에 있습니다. |
| `optional_host_permissions` (`https://*/*`) | 서비스가 자체 결제 화면을 쓰는 경우를 위해, 사용자가 '이 결제창에서 켜기' 또는 '모든 결제창에서 자동으로 켜기'를 직접 눌렀을 때만 요청합니다. 설치 시에는 요청하지 않습니다. |
| 원격 코드 | 사용하지 않습니다. 글꼴을 포함한 모든 파일이 패키지에 들어 있습니다. |
