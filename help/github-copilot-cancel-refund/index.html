Copilot 구독은
개인 결제인지 좌석인지 먼저 보세요.

개인 Copilot 플랜은 GitHub Billing에서 취소하면 현재 결제 주기 말까지 유지된 뒤 Copilot Free로 내려갑니다. 조직·Enterprise가 부여한 좌석은 개인이 결제를 취소할 수 없고 관리자에게 요청해야 합니다.

지금 바로 할 일

GitHub Settings의 Billing & licensing에서 Copilot 항목을 열어 개인 플랜인지 확인하세요. 개인 플랜이면 Manage subscription → Cancel subscription으로 다음 갱신을 막습니다. 공식 문서가 모든 오결제에 대한 일반 환불 기한을 공개하지 않으므로, 이미 결제된 금액은 GitHub Support에 사실관계와 영수증을 보내 개별 검토를 요청합니다.

결제 경로별 실행

결제 경로해지환불
GitHub 웹 결제프로필 → Settings → Billing & licensing → Licensing 또는 Plans and usage → GitHub Copilot → Manage subscription → CancelGitHub Support의 Billing 문의로 인보이스·결제일·사유 제출. 일반 환불 승인을 미리 단정하지 않음

Google Play공식 개인 플랜 관리 문서에 Google Play 결제 경로가 제시되지 않음Google Play 영수증이 실제로 있을 때만 Play 정기 결제·환불에서 해당 항목 확인
조직·Enterprise 좌석개인이 취소할 수 없음. 조직 소유자·Billing Manager에게 좌석 제거 요청조직 청구서 조정은 관리자 계정으로 GitHub Support에 문의
해지와 환불은 별개입니다. 개인 유료 플랜 사용자가 Copilot Business 또는 Enterprise 좌석을 배정받으면 개인 플랜이 자동 취소되고 남은 기간은 비례 환불된다고 공식 문서에 명시되어 있습니다. 이는 모든 취소에 적용되는 일반 환불 규정이 아닙니다.

실수 없이 끝내는 순서

  1. 라이선스 소유자 확인Settings → Billing & licensing에서 개인 결제인지, 조직이 부여한 좌석인지 확인합니다.
  2. 개인 플랜이면 갱신 중단새 Billing 화면의 Licensing 또는 기존 화면의 Plans and usage에서 Manage subscription을 엽니다.
  3. 이미 결제됐다면 지원 요청인보이스 URL·결제일·금액·플랜·실수 사유·사용 여부를 GitHub Support Billing 문의에 첨부합니다.
  4. 추가 사용량도 별도 점검AI credits나 사용량 기반 청구가 있다면 구독료와 구분해 Usage와 예산 설정을 확인합니다.

막히는 경우

Cancel 메뉴가 없음: 학생·교사·인기 오픈소스 관리자 무료 혜택이거나 조직 좌석일 수 있습니다. 이 경우 결제 취소가 아니라 환경에서 Copilot을 비활성화하거나 관리자에게 좌석 제거를 요청합니다.

Business 좌석 배정 후 개인 결제도 보임: 개인 플랜 자동 취소 여부와 비례 환불 내역을 Billing에서 확인하고, 반영되지 않으면 개인 인보이스와 조직명을 함께 지원팀에 보냅니다.

Apple·Google에서 구독이 안 보임: GitHub가 직접 청구한 개인 플랜일 가능성이 큽니다. 카드 명세서와 GitHub 이메일 영수증을 찾아 GitHub Billing에서 처리합니다.

취소 후 기능이 계속됨: 현재 결제 주기 말까지 기능이 유지되는 정상 동작일 수 있습니다. 종료일과 Copilot Free 전환 예정 상태를 확인합니다.
