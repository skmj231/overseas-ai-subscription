# 돈나가요 Donna 1.4.0 제출 순서

## 올릴 파일

- 확장프로그램: `releases/donna-extension-v1.4.0.zip`
- 작은 홍보 이미지: `assets/generated-brand/promo-small-440x280.png`
- 큰 홍보 이미지: `assets/generated-brand/promo-marquee-1400x560.png`
- 스크린샷 1~3: `assets/generated-brand/store-screenshot-01-1280x800.png`부터 `03`까지

## 크롬 웹스토어에서 할 일

1. 개발자 대시보드에서 돈나가요 항목을 엽니다.
2. `패키지`에서 새 ZIP 파일을 업로드합니다.
3. `스토어 등록정보`의 이름을 `돈나가요 Donna: 해외 AI·SaaS 구독 결제 전 알림`로 맞춥니다.
4. 상세 설명은 `listing-description-ko.txt` 내용을 붙여넣습니다.
5. 새 아이콘·홍보 이미지·스크린샷 3장을 업로드합니다.
6. 홈페이지는 `https://donna.co.kr/`, 개인정보처리방침은 `https://donna.co.kr/privacy.html`로 확인합니다.
7. 변경사항 설명에 `release-notes-ko.txt` 내용을 붙여넣습니다.
8. 경고가 없으면 `검토를 위해 제출`을 누릅니다.

`web_accessible_resources`에는 브랜드 아이콘 두 개만 공개됩니다. 결제 데이터나 사용자 정보는 포함되지 않습니다.
