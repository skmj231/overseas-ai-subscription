이렇게 쓰면 됩니다

설치하면 실제 알림이 어떻게 보이는지 예시부터 보여드립니다. 그다음에는 기억나는 서비스 이름만 등록해도 됩니다.

1. 설치하고 처음

설치하면 시작 화면이 자동으로 열립니다. 먼저 예시 알림을 보고, 실제 구독을 등록할지 선택하세요. 예시로 보여드린 ChatGPT 정보는 실제 구독 목록에 저장되지 않습니다.

내 결제금액이나 다음 결제일을 몰라도 괜찮습니다. 서비스 이름만 먼저 적으면 확인 필요 상태로 남겨두고, 나중에 주기와 날짜를 확인했을 때 알림을 시작합니다.

1예시 확인어떻게 알려주는지 먼저 봅니다
→
2이름부터 등록모르는 내용은 비워도 됩니다
→
3정보 완성주기와 날짜가 생기면 알림이 시작됩니다

2. 결제창에서 뜨는 것

결제 화면에 들어가면 왼쪽 아래에 작은 안내가 뜹니다. 금액과 결제 주기를 읽어 다음 결제일을 계산해 보여드립니다. 결제 전에 알려주세요를 누르면 그걸로 끝입니다.

금액을 확신하지 못하는 화면에서는 창을 열지 않고 배지만 조용히 띄웁니다. 눌러 보시면 무엇을 못 읽었는지 알려드립니다.

1결제 화면 열기금액과 결제 주기를 확인합니다
→
2작은 안내 확인다음 결제일을 보여줍니다
→
3알림 켜기버튼 한 번이면 끝입니다

실제 화면을 옮겨 그린 예시라 계정·카드 정보가 보이지 않습니다. GIF 없이도 한눈에 흐름을 이해할 수 있습니다.

3. 알림은 언제, 어떻게

  • 연 구독은 결제 14일 전과 3일 전, 두 번
  • 월 구독은 결제 5일 전과 1일 전, 두 번
  • 무료 체험은 유료로 바뀌기 전에 한 번

크롬 브라우저 알림으로 옵니다. 창을 안 켜 두셔도 크롬이 백그라운드에 살아 있으면 옵니다. 컴퓨터를 완전히 꺼 두셨으면 다음에 켤 때 옵니다. 내 정보 화면에서 알림을 통째로 끄거나, 며칠 전에 받을지 직접 고르실 수 있습니다.

4. 사업자등록번호 넣기

툴바 아이콘을 누르고 내 정보로 가시면 됩니다. 국세청 검증 규칙을 통과한 번호만 저장됩니다. 저장된 번호는 이 브라우저 안에만 있고 어디로도 전송되지 않습니다.

결제창에 사업자번호 칸이 있으면 버튼 하나로 채워집니다. 칸이 없는 서비스는 결제 설정 화면에서 한 번 등록해 두시면 다음 결제부터 부가세가 빠집니다. 이미 결제된 건은 소급이 안 됩니다.

5. 분기 자료 내보내기

결제 기록과 세무 화면에서 이번 분기를 고르고 파일로 내보내시면 됩니다. 결제일, 서비스명, 통화, 외화 금액, 적용 환율, 원화 금액, 부가세액이 들어 있습니다. 세무대리인께 그대로 넘기시면 됩니다.

확실하지 않은 건은 확인 필요로 표시됩니다. 실제 카드 청구액을 아시면 그 자리에서 넣어 주세요. 추정 환율 대신 실제 금액이 들어갑니다.

6. 캘린더에 넣기

내 정보에서 캘린더에 넣기를 누르면 파일이 하나 받아집니다. 구글 캘린더나 아이폰 캘린더에 넣으면 그다음부터는 휴대폰이 대신 알려 줍니다. 컴퓨터를 며칠 안 켜셔도 놓치지 않습니다.

7. 안 뜰 때

서비스가 결제 화면을 직접 만들어 쓰는 경우에는 미리 들어가 있지 않습니다. 그 화면에서 툴바 아이콘을 누르고 이 결제창에서 켜기를 선택하시면 그때 읽습니다. 앞으로 자동으로 켜기를 고르시면 그 사이트 하나에 대해서만 권한을 요청합니다.
